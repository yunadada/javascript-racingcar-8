# javascript-racingcar-precourse

## 구현할 기능 목록

### 1️⃣ 입력값의 유효성을 검증한다. (검증)

> 책임: 전달받은 값(자동차 이름 목록, 시도 횟수)이 게임 규칙에 맞는지 검사한다.

- 각 자동차 이름이 5자 이하인지 검증한다.
- 각 자동차가 올바른 구분자로 구분되어 입력됐는지 검증한다.
- 시도 횟수가 유효한 숫자로 입력됐는지 검증한다.

### 2️⃣ 자동차를 생성한다. (객체 생성)

> 책임: 검증된 자동차 이름 목록을 바탕으로, 경주에 참여할 자동차 객체를 생성한다.

- 각 자동차는 이름과 현재 위치(초기값 0)를 상태로 가진다.

### 3️⃣ 턴별 이동 값을 결정한다. (이동 규칙)

> 책임: 무작위 값을 생성하고 규칙에 따라 턴별 이동 값(1 또는 0)을 반환한다.

- 0에서 9 사이의 무작위 값을 생성한다.
- 무작위 값이 4이상일 경우 1을 반환하고, 4미만일 경우 0을 반환한다.

### 4️⃣ 자동차 경주를 실행한다. (게임 실행)

> 책임: 주어진 횟수만큼 경주를 반복하며, 이동 규칙에 따라 자동차의 위치를 갱신한다.

- 주어진 횟수만큼 경주 라운드를 반복한다.
- 각 자동차마다 이동 규칙에 이동 값(0 또는 1)을 요청한다.
- 반환된 값을 자동차의 현재 위치에 더하여 상태를 갱신한다.
- 각 라운드의 실행 결과를 `이름 : ---` 형식으로 출력한다.

### 5️⃣ 최종 우승자를 판별한다. (결과 판별)

> 책임: 모든 경주가 끝난 자동차 목록을 받아, 최종 우승자를 판별한다.

- 가장 높은 위치 값을 가진 자동차를 우승자로 판별한다.
- 우승자가 여러 명일 경우 쉼표를 이용하여 구분한다.
